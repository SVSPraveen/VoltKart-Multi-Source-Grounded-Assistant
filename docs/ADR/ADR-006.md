# ADR-006: Chat PDF Export Engine

## Status
Accepted

## Context
Candidates and evaluators assess the assistant through exported chat PDFs. The exported PDF must capture full conversation history, exact timestamps with timezones, citations (SQL + result rows for tables, document version + page/heading + verbatim quote for documents), inline charts re-rendered as vector/raster images, and the Indian Rupee symbol (`₹`).

## Decision
Implement server-side PDF generation using **ReportLab** paired with an embedded TrueType Unicode font (**Noto Sans**) and **Matplotlib (Agg backend)** for chart re-rendering.

## Alternatives Rejected
1. **Headless Chrome / Puppeteer (`page.pdf()`):** Requires installing full Chromium browser binaries on backend host machines; brittle font rendering across OS platforms.
2. **WeasyPrint:** Requires heavy system-level C-libraries (Pango, Cairo, GDK-PixBuf) that fail to install cleanly on standard Windows environments.

## Executive Trade-off Analysis
- **User Value:** Lightweight, self-contained Python generation with deterministic Unicode rendering of `₹`.
- **Risk:** Complex multi-page flowable table layout; mitigated by modular ReportLab layout helpers.
- **Cost to Reverse:** Medium.
