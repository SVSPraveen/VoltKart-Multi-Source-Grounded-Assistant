# ADR-004: Agent State Machine Architecture

## Status
Accepted

## Context
The chat assistant must coordinate entity resolution, conversational memory, routing between table and document engines, SQL execution feedback loops, and verification before outputting responses.

## Decision
Adopt **LangGraph** to model the execution as an explicit, inspectable state graph:
`Route` -> `Contextualise` -> `Plan` -> `Tool Execution` (SQL Sandbox / Document Resolver / Search) -> `Verification` -> `Compose`.

## Alternatives Rejected
1. **Unconstrained ReAct Loops:** Autonomous multi-turn agent loops often suffer from non-deterministic looping, unpredictable token costs, and difficulty explaining execution paths during technical defense.
2. **AutoGen / CrewAI:** Excessive multi-agent abstraction overhead with opaque inter-agent messaging.

## Executive Trade-off Analysis
- **User Value:** Deterministic, inspectable, and explainable agent execution with real-time status telemetry.
- **Risk:** LangGraph minor version API updates; mitigated by pinning requirements.
- **Cost to Reverse:** Medium.
