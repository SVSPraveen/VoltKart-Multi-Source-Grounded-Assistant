# ADR-001: Frontend Architecture

## Status
Accepted

## Context
The application requires an interactive chat workspace featuring real-time Server-Sent Events (SSE) streaming, inline citation badges that trigger a collapsible Evidence Drawer, a files library grouping document version families, and inline data charts.

## Decision
Adopt **Vite + React 18 + TypeScript + Tailwind CSS**.

## Alternatives Rejected
1. **Next.js / Remix:** SSR/SSG capabilities are unnecessary for an internal/desktop single-page analytical tool and introduce complex server/client hydration boundaries for SSE streaming.
2. **Vanilla JavaScript / HTML:** Lacks maintainable component lifecycle management required for dynamic drawer toggles, nested citation states, and chart updates.

## Executive Trade-off Analysis
- **User Value:** Instant load times, high-density responsive layout, type safety across streaming events.
- **Risk:** Minor; standard industry stack.
- **Cost to Reverse:** Low; clean API boundaries.
